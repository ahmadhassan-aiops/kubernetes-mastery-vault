# 01. What Is etcd?

**etcd** (pronounced "et-cee-dee") is an open-source, **strongly consistent, distributed key-value store**, used for:

- configuration management
- service discovery
- coordinating distributed systems

## Key Facts

- An **independent open-source project**, not only for Kubernetes. It is a **graduated CNCF** project.
- Stores data as **keys and values** (a NoSQL, document-style store) rather than tables, which keeps it small and fast.
- **Strongly consistent:** every member of an etcd cluster agrees on the same data, using the **Raft** consensus algorithm.
- Default ports: **2379** for clients and **2380** for peer (member-to-member) traffic.

## Try It in the Browser

The **etcd playground** shows a live cluster you can write to, and lets you watch keys replicate and members fail over:

http://play.etcd.io/play

## Why It Matters for the CKA

etcd is the **single source of truth** for a Kubernetes cluster. Every object you create is stored there, so knowing how to **inspect, back up and restore** etcd is a core administrator skill.
