# 05. etcd Practice Tasks

Work through these with `etcdctl` on the [HA cluster](04.%20Building%20a%20Highly%20Available%20etcd%20Cluster.md) (with the environment variables from step 11 exported), or on the [Minikube etcd pod](03.%20Exploring%20etcd%20on%20Minikube.md). Try each task first, then check the solution.

## Tasks

1. Write a key-value pair into the database.
2. Retrieve the value using the key.
3. Update the value for the key.
4. Delete the key from the database.
5. Store a key-value pair with a **Time-To-Live (TTL)**.
6. Check the database after the TTL expires to confirm the key is gone.
7. Store a key-value pair attached to a **lease**.
8. Revoke the lease and observe what happens.

## Solutions

<details>
<summary><b>1 to 4: Write, read, update and delete</b></summary>

```bash
etcdctl put course "CKA"          # 1. write   → OK
etcdctl get course                # 2. read    → course / CKA
etcdctl put course "CKA 2025"     # 3. update  → OK (put overwrites)
etcdctl get course                #    → course / CKA 2025
etcdctl del course                # 4. delete  → 1 (number of keys deleted)
etcdctl get course                #    → (nothing)
```

</details>

<details>
<summary><b>5 and 6: A key with a TTL</b></summary>

etcd v3 has no per-key TTL; a TTL is a **lease**. Grant a lease, then attach the key to it:

```bash
etcdctl lease grant 30
# lease 694d7a3f2b1c4a0e granted with TTL(30s)

etcdctl put session "active" --lease=694d7a3f2b1c4a0e
etcdctl get session                       # → session / active

etcdctl lease timetolive 694d7a3f2b1c4a0e # how long is left

# wait more than 30 seconds
etcdctl get session                       # → (nothing): the key expired with the lease
```

</details>

<details>
<summary><b>7 and 8: A lease, then revoking it</b></summary>

```bash
etcdctl lease grant 600
# lease 694d7a3f2b1c4a12 granted with TTL(600s)

etcdctl put lock/job1 "worker-a" --lease=694d7a3f2b1c4a12
etcdctl put lock/job2 "worker-b" --lease=694d7a3f2b1c4a12
etcdctl get lock/ --prefix              # both keys exist

etcdctl lease revoke 694d7a3f2b1c4a12
# lease 694d7a3f2b1c4a12 revoked

etcdctl get lock/ --prefix              # → (nothing)
```

**Observation:** revoking a lease **immediately deletes every key attached to it**, without waiting for the TTL. Kubernetes uses leases this way for node heartbeats (the `kube-node-lease` namespace) and for leader election. Use `etcdctl lease keep-alive <id>` to keep a lease from expiring.

</details>

The lease IDs above are examples; use the ID your `lease grant` prints.
