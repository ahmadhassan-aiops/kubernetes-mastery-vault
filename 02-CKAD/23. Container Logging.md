# 23. Container Logging

`kubectl logs` shows a container's standard output and error streams.

## Single-Container Pod

`kodekloud/event-simulator` prints a stream of simulated user events:

```yaml
# log-web-pod.yaml
apiVersion: v1
kind: Pod
metadata:
  name: webapp-pod
spec:
  containers:
  - image: kodekloud/event-simulator
    name: simple-webapp
```

```console
[root@client1 ahmad]# kubectl apply -f log-web-pod.yaml
pod/webapp-pod created
```

`-f` **follows** the log live, like `tail -f`:


```bash

```

## Multi-Container Pod

```yaml
# log2-web-pod.yaml
apiVersion: v1
kind: Pod
metadata:
  name: webapp-pod-2
spec:
  containers:
  - image: kodekloud/event-simulator
    name: simple-webapp
  - image: busybox
    name: db
    command:
    - sleep
    - "5000"
```

```console
[root@client1 ahmad]# kubectl apply -f log2-web-pod.yaml
pod/webapp-pod-2 created
[root@client1 ahmad]# kubectl get po
NAME           READY   STATUS              RESTARTS   AGE
webapp-pod     1/1     Running             0          7m8s
webapp-pod-2   0/2     ContainerCreating   0          4s
[root@client1 ahmad]# kubectl logs webapp-pod-2
Defaulted container "simple-webapp" out of: simple-webapp, db
Error from server (BadRequest): container "simple-webapp" in pod "webapp-pod-2" is waiting to start: ContainerCreating
```

Without a container name, `kubectl logs` **defaults to the first container** in the pod. Use `-c` to choose:

```console
[root@client1 ahmad]# kubectl logs webapp-pod-2 -c db
(empty, since sleep prints nothing)

[root@client1 ahmad]# kubectl logs webapp-pod-2 -c simple-webapp
[2025-05-14 11:06:25,141] INFO in event-simulator: USER1 is viewing page1
[2025-05-14 11:06:26,142] INFO in event-simulator: USER2 is viewing page1
[2025-05-14 11:06:27,146] INFO in event-simulator: USER2 is viewing page1
[2025-05-14 11:06:28,147] INFO in event-simulator: USER4 is viewing page3
[2025-05-14 11:06:29,149] INFO in event-simulator: USER3 is viewing page3
[2025-05-14 11:06:30,151] WARNING in event-simulator: USER5 Failed to Login as the account is locked due to MANY FAILED ATTEMPTS.
[2025-05-14 11:06:30,152] INFO in event-simulator: USER4 is viewing page1

[2025-05-14 11:06:34,161] INFO in event-simulator: USER2 logged out
```

Follow one container's logs live:

```bash
kubectl logs -f webapp-pod-2 -c db
```

> **Try it:** use `nginx` as the second container and compare its access logs.

## Log Command Summary

| Command | Purpose |
|---|---|
| `kubectl logs <pod>` | Logs of a single-container pod |
| `kubectl logs -f <pod>` | Follow live |
| `kubectl logs <pod> -c <container>` | One container in a multi-container pod |
| `kubectl logs <pod> --previous` | Logs of the **previous** (crashed) instance |
| `kubectl logs <pod> --tail=20` | Only the last 20 lines |
