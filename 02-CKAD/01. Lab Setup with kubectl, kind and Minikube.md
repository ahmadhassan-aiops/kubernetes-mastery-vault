## kubectl Auto-Completion and the `k` Alias

Saves a lot of typing in the exam and in daily work:

```bash
sudo dnf install -y bash-completion

source <(kubectl completion bash)
echo "source <(kubectl completion bash)" >> ~/.bashrc

echo "alias k=kubectl" >> ~/.bashrc
echo "complete -F __start_kubectl k" >> ~/.bashrc

source ~/.bashrc
```

## Tip: Increasing Disk Space on a RHEL VM

Clusters and images fill a small VM disk quickly. To grow the root partition:

```bash
sudo yum install cloud-utils-growpart
sudo growpart /dev/sda 2
sudo pvresize /dev/sda2
sudo lvextend -L +40G /dev/mapper/cs-root
sudo xfs_growfs /
df -h
```

### Multi-node cluster from a config file

```yaml
# kind-config.yml
kind: Cluster
name: cloudops
apiVersion: kind.x-k8s.io/v1alpha4
nodes:
  - role: control-plane
  - role: worker
  - role: worker
```


### High-availability cluster with pinned versions

Three control-plane nodes and three workers, each pinned to a specific Kubernetes version:

```yaml
# config.yml
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
name: cloudops
nodes:
  - role: control-plane
    image: kindest/node:v1.26.0
  - role: control-plane
    image: kindest/node:v1.26.0
  - role: control-plane
    image: kindest/node:v1.26.0
  - role: worker
    image: kindest/node:v1.25.3
  - role: worker
    image: kindest/node:v1.25.3
  - role: worker
    image: kindest/node:v1.25.3
```

## Minikube

Minikube runs a single-node cluster, which is handy for add-ons like the dashboard and ingress.

### Fixing Minikube not starting

Minikube would not start until memory accounting was enabled for Docker. I added `cgroup_enable=memory swapaccount=1` to the kernel command line in GRUB:

```console
[root@client1 ahmad]# sudo nano /etc/default/grub
[root@client1 ahmad]# cat /etc/default/grub
GRUB_TIMEOUT=5
GRUB_DISTRIBUTOR="$(sed 's, release .*$,,g' /etc/system-release)"
GRUB_DEFAULT=saved
GRUB_DISABLE_SUBMENU=true
GRUB_TERMINAL_OUTPUT="console"
GRUB_CMDLINE_LINUX="crashkernel=1G-4G:192M,4G-64G:256M,64G-:512M resume=/dev/mapper/cs-swap rd.lvm.lv=cs/root rd.lvm.lv=cs/swap rhgb quiet cgroup_enable=memory swapaccount=1"
GRUB_DISABLE_RECOVERY="true"
GRUB_ENABLE_BLSCFG=true
```

Because Docker Desktop was also running, I first switched Docker back to the default context:

```bash
docker context use default
```
