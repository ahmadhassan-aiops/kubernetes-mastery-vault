# 02. Working with Pods

## Create a Three-Node Cluster

```yaml
# config.yml
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
name: cloudops-cluster
nodes:
  - role: control-plane
  - role: worker
  - role: worker
```

```console
[ahmad@client1 ~]$ kind create cluster --config config.yml
Creating cluster "cloudops-cluster" ...
 ✓ Ensuring node image (kindest/node:v1.32.2) 🖼
 ✓ Preparing nodes 📦 📦 📦
 ✓ Writing configuration 📜
 ✓ Starting control-plane 🕹️
 ✓ Installing CNI 🔌
 ✓ Installing StorageClass 💾
 ✓ Joining worker nodes 🚜
Set kubectl context to "kind-cloudops-cluster"
```

A fresh cluster has no pods in the `default` namespace, only the system namespaces:

```console
[ahmad@client1 ~]$ kubectl get pods
No resources found in default namespace.

[ahmad@client1 ~]$ kubectl get ns
NAME                 STATUS   AGE
default              Active   2m21s
kube-node-lease      Active   2m21s
kube-public          Active   2m21s
kube-system          Active   2m22s
local-path-storage   Active   2m17s
```

## A Single-Container Pod

```yaml
# config-pod.yml
apiVersion: v1
kind: Pod
metadata:
  name: cloudops-pod
  labels:
    app: frontend
    version: development
spec:
  containers:
    - name: alpha
      image: nginx
```

```console
[ahmad@client1 ~]$ kubectl apply -f config-pod.yml
pod/cloudops-pod created

[ahmad@client1 ~]$ kubectl get pods
NAME           READY   STATUS              RESTARTS   AGE
cloudops-pod   0/1     ContainerCreating   0          9s

[ahmad@client1 ~]$ kubectl get pods
NAME           READY   STATUS    RESTARTS   AGE
cloudops-pod   1/1     Running   0          3m37s
```

`-o wide` shows the pod's IP and the node it was scheduled on:

```console
[ahmad@client1 ~]$ kubectl get pods -o wide
NAME           READY   STATUS    RESTARTS   AGE    IP           NODE                      NOMINATED NODE   READINESS GATES
cloudops-pod   1/1     Running   0          4m4s   10.244.2.2   cloudops-cluster-worker   <none>           <none>
```

## Inspecting Pods

```bash
kubectl describe pod cloudops-pod   # full details and events
kubectl get pods --watch            # live status changes
```
