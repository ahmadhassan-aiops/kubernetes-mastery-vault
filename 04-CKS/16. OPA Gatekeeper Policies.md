# 16. OPA Gatekeeper Policies

## What Is OPA?

**Open Policy Agent (OPA)** is a general-purpose policy engine that **separates policy decisions from application code**. Policies are written in **Rego**, a declarative language.

In Kubernetes, OPA runs as **Gatekeeper**, an **admission controller**: every create or update request reaches Gatekeeper after authentication and authorization, and Gatekeeper rejects objects that break a policy.

> Gatekeeper is one way to replace **PodSecurityPolicy**, which was removed in Kubernetes 1.25. The built-in replacement is Pod Security Admission (see [topic 15](15.%20Security%20Contexts%20for%20Least%20Privilege.md)); Gatekeeper adds **custom** rules on **any** object.

## Key Components

| Component | Purpose |
|---|---|
| **ConstraintTemplate** | Defines the policy logic in Rego, and creates a new constraint *kind* |
| **Constraint** | An instance of that kind: applies the template to specific resources |
| **Gatekeeper** | The admission webhook that evaluates requests, plus an audit process that reports existing violations |

## Policy 1: Block Privileged Containers

```yaml
# privileged-containers-template.yaml
apiVersion: templates.gatekeeper.sh/v1beta1
kind: ConstraintTemplate
metadata:
  name: k8sblockprivileged
spec:
  crd:
    spec:
      names:
        kind: K8sBlockPrivileged
  targets:
  - target: admission.k8s.gatekeeper.sh
    rego: |
      package k8sblockprivileged

      violation[{"msg": msg}] {
        c := input.review.object.spec.containers[_]
        c.securityContext.privileged
        msg := sprintf("Privileged container '%v' is not allowed", [c.name])
      }
```

```yaml
# privileged-containers-constraint.yaml
apiVersion: constraints.gatekeeper.sh/v1beta1
kind: K8sBlockPrivileged
metadata:
  name: no-privileged-containers
spec:
  match:
    kinds:
    - apiGroups: [""]
      kinds: ["Pod"]
```

```bash
kubectl apply -f privileged-containers-template.yaml
kubectl apply -f privileged-containers-constraint.yaml
```

Test it:

```bash
kubectl run priv --image nginx --overrides='{"spec":{"containers":[{"name":"priv","image":"nginx","securityContext":{"privileged":true}}]}}'
# Error from server (Forbidden): admission webhook "validation.gatekeeper.sh" denied the request:
# [no-privileged-containers] Privileged container 'priv' is not allowed

kubectl run normal --image nginx     # created
```

From now on, only non-privileged pods can be created.

### How the Rego works

- `input.review.object` is the object being created.
- `containers[_]` loops over every container.
- A `violation` is produced when **every** line in the block is true. Each violation's `msg` is returned to the user and the request is denied.

> Note on the logic: binding the container (`c := ...[_]`) once and using `c` throughout makes sure the message names the container that is actually privileged.

## Policy 2: Allow Images Only from a Trusted Registry

```yaml
# registry-template.yaml
apiVersion: templates.gatekeeper.sh/v1beta1
kind: ConstraintTemplate
metadata:
  name: k8sallowedrepos
spec:
  crd:
    spec:
      names:
        kind: K8sAllowedRepos
  targets:
  - target: admission.k8s.gatekeeper.sh
    rego: |
      package k8sallowedrepos

      violation[{"msg": msg}] {
        container := input.review.object.spec.containers[_]
        not startswith(container.image, "docker.io/trusted/")
        msg := sprintf("Container '%v' uses untrusted registry", [container.image])
      }
```

```yaml
# registry-constraint.yaml
apiVersion: constraints.gatekeeper.sh/v1beta1
kind: K8sAllowedRepos
metadata:
  name: only-trusted-registries
spec:
  match:
    kinds:
    - apiGroups: [""]
      kinds: ["Pod"]
```

Pods can now only use images whose name starts with `docker.io/trusted/`. Replace the prefix with your own registry (for example `registry.example.com/`). Remember that an image written as just `nginx` doesn't start with `docker.io/`, so it will be rejected.

## Policy 3: Require Resource Limits

```yaml
# resource-template.yaml
apiVersion: templates.gatekeeper.sh/v1beta1
kind: ConstraintTemplate
metadata:
  name: k8sresourcelimits
spec:
  crd:
    spec:
      names:
        kind: K8sResourceLimits
  targets:
  - target: admission.k8s.gatekeeper.sh
    rego: |
      package k8sresourcelimits

      violation[{"msg": msg}] {
        container := input.review.object.spec.containers[_]
        not container.resources.limits
        msg := sprintf("Container '%v' has no resource limits", [container.name])
      }
```

```yaml
# resource-constraint.yaml
apiVersion: constraints.gatekeeper.sh/v1beta1
kind: K8sResourceLimits
metadata:
  name: require-resource-limits
spec:
  match:
    kinds:
    - apiGroups: [""]
      kinds: ["Pod"]
```

Every pod must now define CPU and memory limits in its manifest, or it won't be created. (Resource limits themselves are covered in [CKAD topic 17](../02-CKAD/17.%20Resource%20Requests%20and%20Limits.md).)

> These constraints match **Pods**. A Deployment is still accepted, but its ReplicaSet can't create the pods: check `kubectl describe rs` for the denial message.

## Managing Templates and Constraints

```bash
kubectl get constrainttemplates
kubectl get constraints                      # all constraints of all kinds

kubectl describe k8sblockprivileged no-privileged-containers   # includes audit violations
```

Delete a **constraint** with `kubectl delete <constraint-kind> <constraint-name>`:

```bash
kubectl delete K8sBlockPrivileged no-privileged-containers
kubectl delete K8sResourceLimits require-resource-limits
```

Delete a **template** by its metadata name (the lowercase one). Deleting a template also removes its constraint kind and all its constraints:

```bash
kubectl delete constrainttemplate k8sblockprivileged
```

## Tips

- Use `enforcementAction: dryrun` (or `warn`) in a constraint's `spec` to try a policy without blocking anything.
- Limit a constraint to certain namespaces with `spec.match.namespaces`, or exclude system namespaces with `excludedNamespaces`.
- The **Gatekeeper policy library** has ready-made, tested templates: https://open-policy-agent.github.io/gatekeeper-library/
